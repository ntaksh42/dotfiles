# 語彙と言い換え

## 計測の方法と限界

Zenn の技術記事で、AI 普及前（2022 年 10 月以前、人気順 250 本）と 2026 年 9 月下旬（新着 250 本）の出現率を比べた。2026 年側は全体が AI 生成ではないので、数値は「AI が広まった後に増えた」ことを示すだけで、「AI が書いた」ことの証明ではない。話題の影響も受ける（エージェント関連の記事が増えたため、「止まる」「届く」「数える」が増えた、など）。

Linter が使うのは次の指標。

| 指標 | AI 普及前 | 2026 年 |
|---|---|---|
| 比喩動詞の6形（下表） | 0.0% の記事 | 7.6% |
| ダッシュ記号 | 3.6% | 22.4% |
| 太字として表示されない `**` | 1.2% | 8.8% |
| 太字の密度が目安超え | 10.0% | 27.2% |
| 「ではなく」の密度が目安超え | 10.0% | 30.8% |
| 急増語が3種以上重なる | 0.0% | 14.4% |

## 比喩動詞の6形

| 検出する形 | 普及前 → 2026（記事数） | 例 | 直し方 |
|---|---|---|---|
| 黙って・静かに・そっと＋失敗系の動詞 | 0 → 6 | 設定の誤りは黙って無視される | 気づかないうちに無視される |
| 〜側・方向に倒す | 0 → 6 | 安全側に倒す | 安全を優先する |
| 時間・工数が溶ける | 0 → 1 | 調査に半日溶かした | 調査に半日かかってしまった |
| 一つずつ潰す | 0 → 2 | 不具合を一つずつ潰す | 不具合を一つずつ直す |
| 地味に・じわじわ効く | 0 → 3 | この設定が地味に効く | この設定は目立たないが助けになる |
| 設計・内部・詳細に踏み込む | 0 → 1 | 内部実装に踏み込む | 内部実装を詳しく見る |

直すときは、比喩が帯びていた気持ちを別の言葉で残す。「溶かした」の後悔は「かかってしまった」に、「黙って」の気づけなさは「気づかないうちに」に移す。次の置き換えは、元の文や前後から根拠が分かるときだけ使う。

- 「黙って無視される」→「エラーを出さずに無視される」: エラーが出ないと明らかなとき。
- 「壊れる」→「整合性が失われる」: 整合性の話だと明らかなとき。

次の語は、増えているが技術的な用法が多く、単独では検出しない。

| 語 | 普及前 → 2026（記事数） | 残す用法の例 |
|---|---|---|
| 効く | 28 → 67 | キャッシュが効く |
| 回す | 27 → 55 | ジョブを回す |
| 拾う | 3 → 28 | イベントを拾う |
| 落ちる | 14 → 35 | 精度が落ちる |
| 壊れる | 16 → 45 | ビルドが壊れる |
| 「〜した瞬間」 | 3 → 14 | 更新された瞬間にキャッシュを消す |

## 2026 年に増えた語

語自体は正当なので、1 記事に 3 種以上重なったときだけ info を出す。

| 語 | 普及前 → 2026（記事数） | 言い換えの方向 |
|---|---|---|
| 実測 | 1 → 51 | 実際に測った値 |
| 照合・突き合わせ | 1・0 → 28・16 | 照らし合わせる、見比べる |
| 入口 | 2 → 28 | 手始め |
| 落とし穴 | 2 → 19 | 見落としやすい点 |
| 事故 | 4 → 23 | 思いがけない失敗 |
| 取り違え・断定 | 0・0 → 13・16 | 勘違い、言い切る |

## 区別できなかったもの（検出に使わない）

| 指標 | 普及前 | 2026 年 |
|---|---|---|
| 本質・本質的（記事数） | 17・13 | 4・4 |
| 解像度（記事数） | 9 | 7 |
| 重要なのは（記事数） | 10 | 19 |
| 参考になれば（記事数） | 15 | 9 |
| というわけです（記事数） | 10 | 0 |
| 絵文字（1000 字あたり平均） | 0.40 | 0.24 |
| 日英間の半角空白（同） | 12.6 | 13.7 |
| 文末コロン（同） | 0.12 | 0.07 |
| 箇条書き比率（平均） | 0.16 | 0.16 |
| 同一文末の3連続（該当する記事の割合） | 76.8% | 67.6% |

手触り、羅針盤、美学、境地などは、どちらの年代の技術記事にもほぼ出ない。エッセイや note では出るかもしれないが、この計測では裏付けが取れていない。

## 冗長な言い回し（AI の指標ではない）

端的にする作業の対象だが、AI 普及前の記事のほうが多い。2026 年側は文も短い。このため warn には入れず、`--concise` の hint にだけ出す。

| 指標 | 普及前（中央値） | 2026 年（中央値） |
|---|---|---|
| 平均文長（字） | 41.3 | 33.4 |
| ことができる（1000 字あたり） | 0.37 | 0.00 |
| ということ・という点（同） | 0.26 | 0.00 |
| することで・によって（同） | 0.43 | 0.00 |
| のです・わけです（同） | 0.40 | 0.00 |

2026 年側の問題は冗長さより、削りすぎた体言止めと名詞の連なりのほうにある。端的にするときも、この方向へ寄せない。
