操作の詳しい説明
ブロックにホバー / タップで「✎ 直す」が出ます。クリック / タップで開く編集画面は 左 = Markdown の入力欄、右 = 入力に追従するプレビュー (「差分」で赤マーク付き)。確定 = ボタン or ⌘/Ctrl+Enter、取消 = ボタン or Esc。直したブロックは左に赤い罫と「直された n 文字」+ 1 行の要約。表はセルごとの入力欄 (行や列を足す/消すときは「Markdown を直接直す」)。追加は編集画面の「＋ この下に段落を足す」(PC ではブロックの間の「＋ ここに段落を足す」でも)、削除は編集画面の「削除」(「元に戻す」で復活)。本文のリンクは新規タブで開きます (リンクの文言を直すときは、その周りの文字をクリック)。メタ情報 (HTML コメント) は記事には出ませんが、出力では位置ごと保持されます。
