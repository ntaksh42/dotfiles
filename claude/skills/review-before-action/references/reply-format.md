# 【レビュー回答】固定形 — 3 モード共通の貼り戻し契約

> ここの `0.3.0` は**回答テキストの契約**の版。`references/sheet-spec.md` の `v3` は
> **標準モードのシートの体裁**の版で、別系統。混同しない。

人がブラウザの [貼り付ける文章を作る] を押すと、この形のテキストがクリップボードと textarea に出て、人が Claude Code のターミナルに貼って Enter する。agent はこの形だけを読む。

## 形

```
【レビュー回答】<label>
Q1. <質問>: A — <選択肢> / 補足: <自由記述>
Q2. <質問>: (未選択 = お任せ)
全体へのコメント: <自由記述 (複数行あり得る)>
## 指摘
#12 [短くする] <ひとこと>
#15 [ここは良い]
## 添削
- 段落 3: 「旧の語」→「新の語」
- 段落 7: (削除)
```markdown
<完成形 Markdown 全文>
```
---
上の回答を反映して作業を続けてください。お任せの項目は推奨案で確定してください。
```

## 規則

- 1 行目 `【レビュー回答】<label>` と末尾の `---` + 締めの 1 文は **全モード必須・不変**
  - 0.3.0 で見出しを旧 `【赤ペン回答】` から `【レビュー回答】` に変更した (0.2.0 以前とは非互換)。シートは証跡として消さずに残す運用 (SKILL.md 手順 11) なので、**旧版で作った HTML が人の手元やリポジトリに残っており、そこから貼り戻される可能性がある**。`【赤ペン回答】` で始まるテキストが来たら、同じ固定形として読んでよい。新しく作るシートは必ず新見出しで出す
- `Qn. <質問>: A — <選択肢> / 補足: <自由記述>` — 標準モードの択一。未選択は `(未選択 = お任せ)`。補足が空なら ` / 補足:` を省く
- `全体へのコメント:` — 自由記述。次の見出し (`## `) か `---` までが本文
- `## 指摘` — 指摘モードのみ。`#<ブロック番号> [<チップ>] <ひとこと>`。チップだけの行もある。ブロック番号は原稿の DOM 順 (sheet 内で `data-blk` として見える)
- `## 添削` — 添削モードのみ。語単位の差分行を段落ごとに並べ、その後に完成形 Markdown の全文をコードブロックで載せる。長い貼り付けは Claude Code が「[Pasted text]」に畳むので実用上問題ない
- 空の節は出さない (指摘 0 件なら `## 指摘` 自体を出さない)
- テンプレを改造するときもこの形を崩さない
